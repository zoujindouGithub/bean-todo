# 豆芽待办 · 微信小程序（本地存储版）

一个基于**原生微信小程序框架**的待办事项应用。数据保存在**小程序本地缓存**（`wx.setStorageSync`），**不依赖云开发、不依赖任何后端服务**，离线可用、点开即用。

## 功能特性

- 待办列表：统计卡片（全部 / 进行中 / 已完成）、过滤 Tab。
- 新增 / 编辑待办：标题、描述、优先级（低 / 中 / 高）、到期日。
- 一键切换完成态、长按删除。
- 下拉刷新、空状态提示。

## 快速开始

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择「**导入项目**」，目录指向本项目根目录（`project.config.json` 所在目录）。
3. AppID 已填为本项目的小程序 AppID `wxcec5a0f51ae11d93`，直接确定即可。
4. 点击「**编译**」——模拟器直接可用，**无需任何云环境配置**。

> 与之前最大的区别：不再需要在云开发控制台开通环境、创建集合、导入权限规则。导入项目后编译即可跑通。

## 数据存储说明

| 项 | 说明 |
| --- | --- |
| 存储位置 | 小程序本地缓存，key = `bean_todo_items_v1` |
| 存储格式 | 待办对象数组（JSON 可序列化） |
| 容量上限 | 单个 key 1MB、总量 10MB（微信官方限制）；纯文本待办远低于此 |
| 隔离性 | 微信本地缓存按「小程序 + 用户」隔离，不同用户 / 不同小程序互不可见 |
| **数据持久性** | **卸载小程序、或在微信「设置 → 通用 → 存储空间」清理后数据会丢失** |
| **多设备** | **不跨设备同步**：换手机、以及在开发者工具与真机之间，数据各自独立 |

### 怎么清空本地数据（调试用）

- **开发者工具**：顶部「清缓存」→「清除数据缓存」。
- **真机**：微信「发现 → 小程序」里删除该小程序，或「设置 → 通用 → 存储空间」清理。

## 发布上线

### 0. 前置：设置服务类目

登录 [微信公众平台](https://mp.weixin.qq.com) → 该小程序 → 「设置 → 基本设置 → 服务类目」，选择贴近的类目（如「工具 → 效率」或「信息查询」，以平台当时可选列表为准）。

### 1. 上传代码

开发者工具右上角「**上传**」→ 填版本号（如 `1.0.0`）与项目备注 → 确定。上传成功后代码会出现在公众平台的「版本管理」里。

### 2. 提交审核（**必须先完成备案**）

> ⚠️ **自 2023 年 9 月 1 日起，所有新注册小程序必须先完成备案才能上架发布。** 个人主体同样需要备案。**未备案只能上传和预览，无法提交审核发布。**

备案流程（在公众平台操作，入口在首页「去备案」）：

1. **填写备案信息**：主体信息（个人：身份证正反面彩色照片）、主体负责人信息（手机号需实名且与身份证一致）、小程序信息、小程序负责人信息。
2. **人脸核身**：个人主体默认复用主体负责人信息；核验时用纯白/浅色背景，面部无遮挡。
3. **平台初审**：1–2 个工作日，保持电话畅通。
4. **工信部短信核验**：初审通过后收到 12381 短信，**须在 24 小时内**登录 [beian.miit.gov.cn](https://beian.miit.gov.cn/) 完成核验，否则会被自动驳回。
5. **通管局审核**：1–20 个工作日。
6. **备案成功**：下发小程序备案号，即可提交审核。发布后备案号自动展示在小程序资料页，无需自行悬挂。

> 三件事都通过后，回公众平台「版本管理」→「提交审核」→ 审核通过后点「发布」。
> **本地开发与真机预览不需要备案**，只有正式发布才需要。

## 可选：将来要改成云端同步

当前接口已按「可替换实现」设计：`utils/todo.js` 导出 `TodoManager`，页面只依赖 `list / get / create / update / toggle / remove / clearCompleted` 这 7 个方法。

若以后需要**多设备同步**：

1. 在 `app.js` 的 `onLaunch` 里补上云环境初始化：
   ```js
   wx.cloud.init({ env: '<你的环境 ID>', traceUser: true });
   ```
2. 把 `utils/todo.js` 内部实现替换为 `wx.cloud.database()` 版本（**页面代码无需改动**）。
3. 在云开发控制台创建 `todos` 集合并导入 `cloudbase/security-rules/todos.json` 的权限规则。

> 注意：用云开发时，**云环境必须在微信侧创建**（在微信开发者工具里新建），
> 腾讯云控制台/CLI 创建的环境（Source 为 `CloudBase`）目前只支持 Web 端，小程序端会报「环境不存在」。

## 数据模型（utils/todo.js 内部字段）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_id` | string | 本地生成的唯一 id |
| `title` | string | 标题（必填） |
| `desc` | string | 描述（可空） |
| `priority` | string | 优先级：`low` / `normal` / `high`，默认 `normal` |
| `completed` | boolean | 是否完成，默认 `false` |
| `dueDate` | string | 到期日，如 `2026-08-30`（可空） |
| `createdAt` | number | 创建时间（毫秒时间戳） |
| `updatedAt` | number | 更新时间（毫秒时间戳） |
| `completedAt` | number \| null | 完成时间（毫秒时间戳） |

## 说明

- 不引入云函数、不引入任何第三方依赖，纯原生小程序。
- 所有存储读写均有 `try/catch`，错误通过 `wx.showToast` 或 `console.error` 暴露，不吞异常。
- 本地缓存数据损坏（非数组 / 脏数据）时会被安全过滤为空数组，不会导致页面崩溃。
